# GitHub Dev Days Ottawa

This repository preserves the presentations and resources from **GitHub Dev
Days Ottawa**, a community event that brought developers, technical leaders,
and GitHub enthusiasts together to learn, build, and connect.

## About the event

GitHub Dev Days Ottawa featured practical sessions, live demonstrations, and
conversations about modern software development. Attendees explored
AI-assisted development, data and analytics, multilingual experiences, and
ways to extend GitHub Copilot beyond everyday code completion.

The event has concluded, but its session materials remain available here for
the community to revisit and share.

## Event highlights

- Technical talks and hands-on demonstrations
- Practical examples of GitHub Copilot and AI-assisted development
- Data experiences built with Databricks and Microsoft Fabric
- Bilingual and accessible application experiences
- Connections across the Ottawa developer community
